# 🃏 Decks

Every Magic: The Gathering deck tracked in this repo lives here, one directory per deck.

```
decks/
└── <deck-name>/
    ├── card-list.md   # the deck itself
    └── commander.md   # (optional) commander's Scryfall card table
```

---

## 📁 What's in a deck directory

### `card-list.md` — required

The deck list. One card per line: `<count> <card name>`.

```markdown
# Morska, the Unpredictable

## Commanders
1 Morska, the Unpredictable

## Ramp
1 Sol Ring
1x Arcane Signet
5 Forest
```

- Headers (`#`, `##`) and blank lines are ignored — use them freely to organize the list.
- The `x` after count (`1x`) is optional.
- This is the file `verify-deck` reads.

### `commander.md` — optional

A saved snapshot of the commander's card details, generated by `verify-card`. Handy for
quickly checking mana cost, oracle text, or price without hitting Scryfall again.

```bash
verify-card "Morska, Undersea Sleuth" > decks/morska/commander.md
```

---

## ➕ Adding a new deck

1. Make the directory:
   ```bash
   mkdir decks/<deck-name>
   ```
2. Create `decks/<deck-name>/card-list.md` using the format above.
3. **Verify every card name before adding it** — don't rely on memory for exact spelling:
   ```bash
   verify-card "Card Name"
   # or
   make card.verify NAME="Card Name"
   ```
4. Verify the whole list once it's written:
   ```bash
   verify-deck decks/<deck-name>/card-list.md
   ```
5. (Optional) Save the commander's card table:
   ```bash
   verify-card "Commander Name" > decks/<deck-name>/commander.md
   ```
6. Commit the new deck directory.

---

## ✅ Verifying an existing deck

```bash
verify-deck decks/<deck-name>/card-list.md
```

```
Checking 99 unique card lines against Scryfall...

  OK    1 Sol Ring
  OK    5 Forest
  FAIL  1 Typo Card Name  -> Card not found

98/99 verified.
```

Exit code `0` = all cards found, `1` = at least one miss.
